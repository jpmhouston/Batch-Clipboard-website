# Beta 2 of Batch Clipoboard Version 2.0 is Out

The second beta of Batch Clipboard 2.0 for macOS is now available on TestFlight and GitHub.

This version demos a feature that hides the menu bar icon until you use the global copy keyboard shortcut (defaults to Control-Command-C) to collect a set of clipboard items, and after pasting the last (Control-Command-V) the icon disappears again. To try this, get the TestFlight version and complete the sandbox in-app purchase (you won't be charged), then check the Advanced panel in the Setting window.

The non-App Store version from GitHub also re-enables Sparkle self-updates, now with a checkbox in Settings to receive beta updates vs only final releases. Sorry there are no updates from previous versions to 2.0 beta 1 or 2, only going forward (although once 2.0 is final, I will make sure version 1.0.x will update to it).
