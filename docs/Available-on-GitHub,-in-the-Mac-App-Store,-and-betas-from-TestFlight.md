A free direct-download version of Batch Clipboard is [on GitHub](https://github.com/jpmhouston/Cleepp/releases)
which can also be installed as a homebrew cask, or built from source.

It's also available for download [on the Mac App Store](https://apps.apple.com/app/batch-clipboard/id6695729238)
with forthcoming beta releases potentially available again [from TestFlight](https://testflight.apple.com/join/epg3cusH).

These two somewhat separate editions have the same features,
however the App Store version also has a few extra features
unlocked by a reasonable, one-time in-app purchase.
App Store purchases will help to support this application and
more that are forthcoming for macOS and other platforms.
See [here for more information](https://github.com/jpmhouston/Cleepp/wiki/Bonus-Features-for-the-Mac-App-Store-Version)
about the additional features unlocked by the in-app purchase.

To support the development of Batch Clipboard outside of the
in-app purchase in the App Store version,
[tips at buymeacoffee.com](https://www.buymeacoffee.com/bananameterlabs)
are greatly appreciated as well.
